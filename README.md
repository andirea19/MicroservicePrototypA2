# MicroservicePrototypA2
Es muss ein Prototyp erstellt werden, welcher zumindest eine Funktionalit der fiktiven Anwendung abbildet. Die Erstellung des Codes bzw. etwaiger Konfiguration kann mit AI basierten Systemen erfolgen. Der Prototyp muss auf Basis von Docker erzeugt werden und eine Anleitung zum Starten muss entsprechend in der Abgabe bereitgestellt werden.

Bei der Erstellung des Prototypen wurde das Tutorial von FreeCodeCamp verwendet: https://www.freecodecamp.org/news/how-to-create-microservices-with-fastapi/

Es handelt sich um eine Wunschliste für Haustiere, ähnlich wie eine Wishlist auf Amazon, wo Tiergeburtstage und vorgeschlagene Geschenke verwaltet werden.
